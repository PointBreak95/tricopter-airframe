# tricopter-airframe

A custom tricopter airframe designed, built, and flight tested.

Previous frame failed from manufacturing issues. That frame was 3D printed out of matte PLA (just what I had on hand).
3D printed horizontally so frame split along layer lines during testing. 
Friction fit with screws into plastic also relatively unstable. Battery was loose and could slip at certain angles during flight.
Similar issue with PixHawk flight controller.

Requirements for new airframe:
- reinforced body
- sturdier arm attachments
- mounting points for avionics
- smaller form factor

Predictions:
- Printing airframe body at angles to prevent layer line cracks
- Using threaded inserts to create stronger and modular arm attachments
- reinforce avionics

Tests:
- airframe structural load test
- motor thrust force test
- Still figuring other variables that might need to be tested
